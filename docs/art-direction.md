# Art direction / generation record

## 2.0 animation update

The approved 24-frame atlas is unchanged (Git blob `04bbd3b975dae48decded8b9bf77668471521c76`). All character screenshots use that original image. Version 2.0 adds a 14 × 18 quad mesh for restrained hair/head/body movement and time-based pose easing; jump, dance, and stretch reuse existing frames. It does not introduce a 3D model, new generated artwork, or a Live2D rig. Distinct action frames are not cross-dissolved to avoid ghosted faces and limbs.

Tool: built-in `image_gen` (not the CLI/API fallback). Character illustration generated as an original fan-art atlas, then refined through the same tool for transparent edges. Final asset: `assets/anon-atlas.png`, 1024 × 1536 RGBA; four columns, six rows. The runtime selects cells directly and adds subtle movement. No original wallpaper is included.

## Generation prompt

Use case: stylized-concept. Asset type: production 2D desktop companion animation sprite atlas, transparent PNG. Create a polished kawaii anime chibi Chihaya Anon (千早愛音) from BanG Dream It's MyGO!!!!!: recognizable long pastel pink hair with soft bangs and a tiny dark hair clip, large gray-blue eyes, expressive blush, navy blue short-sleeved stage jacket over white blouse, navy pleated skirt, black ankle boots. Fully clothed, cute 2.5-head-tall human chibi, clean expressive linework, premium Japanese game mascot cel shading. EXACT sprite atlas layout: 4 equal columns and 6 equal rows, 24 cells, canvas portrait aspect 2:3 (ideally 1024x1536). Every cell is an equal square. Each cell contains exactly one same-size full-body character, centered, with at least 12% transparent padding all around. Ground baseline at 87% of each cell. ALL cells the same character design, head size, proportions, costume, viewpoint; no camera movement. NO grid lines, NO text, NO labels, NO backgrounds, NO shadows behind cells, no checkerboard. Transparent pixels between characters. Each ROW is a coherent four-frame loop, reading left to right: Row1 idle: neutral smile, gentle breathing, blink with closed eyes, open eyes smile. Row2 walking toward screen right: four distinct alternating leg/arm steps, slight 3/4 view, hair trailing; same baseline. Row3 happy head-pat reaction: surprised pink blush, pleased closed eyes hands near cheeks, bright happy wave, bashful smile. Row4 playing her pale mint-green electric guitar: holding guitar, strumming down eyes open, strumming up eyes closed singing, strumming down happy; guitar fits each cell. Row5 sleepy: seated curled up sleepy, seated eyes closing, seated asleep tiny breathing, seated asleep nod; keep full body inside cell. Row6 being gently picked up: arms lifted surprised, little legs kicking left, legs kicking right cheeks puffed, dangling smiling; safe playful expression. Crisp high quality attractive illustration; actual pose changes within each loop, not duplicates. Do not draw accessories spilling into adjacent cells.

## Transparency refinement prompt

Use case: background-extraction. Edit target is the supplied 1024x1536 4-column by 6-row Chihaya Anon animation sprite atlas. Preserve ALL 24 character drawings, exact layout, poses, scale, color and position. Remove ONLY the dusty mauve/pink rectangular background and any cast background shadows completely from between and around all the sprites. Output genuinely fully transparent empty pixels, not a translucent colored background, not a checkerboard graphic, no gradient. Keep character interiors fully opaque and clean antialiased edge alpha. Maintain EXACT 1024x1536 size and four columns six rows; do not rearrange, resize, add or remove a character. The entire empty area including all corners and grid gutters must be alpha=0. This will be displayed on a desktop without any rectangular backdrop.
